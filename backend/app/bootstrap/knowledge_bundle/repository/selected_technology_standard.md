# Selected Technology Standard

Этот документ входит в **обязательный пакет знаний MVP** и играет роль выбранного технологического стандарта для демо-контура.

Минимальные правила:
- solution должен содержать технологические решения только в терминах, пригодных для эксплуатации и интеграции;
- выбор технологического стека должен быть увязан с boundary type, внешними интерфейсами и ограничениями интеграции;
- verification проверяет, что технологические указания не противоречат архитектурной структуре и описанным интеграциям.
