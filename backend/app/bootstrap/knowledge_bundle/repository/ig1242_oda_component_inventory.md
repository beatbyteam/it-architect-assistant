# IG1242 / ODA Component Inventory

Этот документ входит в **обязательный пакет знаний MVP**.

Минимальные требования для решения:
- решение должно описывать ключевые компоненты и их роли;
- нужно явно показывать интеграции между компонентами и внешними системами;
- в solution должны быть выделены риски и ограничения;
- verification проверяет, что решение не противоречит составу и ролям компонентного ландшафта.
