# ArchiMate 3.2 Modelling Rules

Этот документ входит в **обязательный пакет знаний MVP**.

Минимальные правила моделирования:
- структура решения должна быть разложена по осмысленным разделам;
- компонент, интеграция и риск должны описываться явно, без смешения ролей;
- связи и интерфейсы должны быть прослеживаемыми от текстового описания к структурной части решения;
- verification отмечает отсутствие критичных структурных элементов как `failed` или `warning` в зависимости от тяжести пробела.
