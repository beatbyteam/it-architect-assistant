# Integration Patterns

Этот документ относится к **справочной части базы знаний**.

Подсказки для generation:
- интеграции должны раскрывать source system, target system и protocol;
- взаимодействия должны быть описаны так, чтобы verification мог проверить их согласованность со структурой решения;
- отсутствие этих сведений допустимо только как warning, если остальная часть решения остаётся воспроизводимой.
