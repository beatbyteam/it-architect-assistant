# Baseline Guidelines

Этот документ оставлен как справочная памятка для демо-контура.

Актуальные правила MVP:
- пользователь управляет knowledge sources, source documents, update runs, candidate versions и activation;
- rollback не является пользовательской функцией MVP;
- отдельная консоль администрирования и отдельные ролевые сценарии не входят в обязательный MVP scope.
